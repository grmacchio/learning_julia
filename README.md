# ``learning_julia``

## Why I learned Julia?

I decided to learn Julia to a fuller understanding. Previously my primary
language was Python. I decided to switch because of the following observations.

1. Default Julia is faster than default Python.
2. JAX in Python allows one to do JIT compilation, however, the Python language
is not.
3. Julia is a functional programming language; thus, it is intimately connected
to category theory.
4. Julia has many built in mathematical concepts and symbols.
5. LEAN is also a functional programming language.
6. Julia's idea of multiple dispatch is polymorphism.

Although Julia is a great language, what I will likely miss from Python is the
following.

1. Python has a massive machine learning (ML) community.
2. PyTorch provides is a simple, but powerful, package for optimization.
